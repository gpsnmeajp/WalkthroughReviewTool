# WalkthroughReviewTool

AIが作成したコードを、人間が全文と設計の解説を並べて読むためのスキルです。  
大量に作成されたコードでも、じっくり腰据えて点検したいときに便利です。

AIが対象を選定し、入力作成、HTML生成、解説、自己確認、修正まで行い、ウォークスルー形式のレビュー資料を渡します。  
コードの取り込みはpythonコードが機械的に行うので、書けたり飛んだりすることはありません。

気になった箇所は、コードの `[?]` ボタン あるいは解説カード内の質問ボタンを押すことで、コーディングエージェントに質問するプロンプトが表示されます。

## 使い方

レビューするプロジェクトをAIエージェントで開き、導入済みのスキルに依頼します。

> walkthrough-reviewスキルを実行

あるいは

> 今回の変更に対してwalkthrough-reviewスキルを実行

指定がなければ、現在のプロジェクトを全体レビューします。差分を見たい場合は「今回の差分を対象にして」と添えます。対象・モード・出力先の決定、JSONやパッチの準備、コマンド実行はAIが担当します。

完成した `index.html` をブラウザーで開いて読みます。資料を保存・共有するときは、同梱の `assets/` などを含むレビューのフォルダ全体を保持してください。

## 導入

利用に必要なのは **[skills/walkthrough-review/](skills/walkthrough-review/SKILL.md) 一式**です。利用するAI環境のスキル導入機能で `.skill` を取り込むか、ZIPを展開した `walkthrough-review/` フォルダをスキル探索先に置きます。`SKILL.md` だけでは動作しません。

このリポジトリをAIエージェントで開いている場合は、[AGENTS.md](AGENTS.md) が同梱スキルへ案内します。スキルの配布物を作る手順は [dev/README.md](dev/README.md) にあります。

必要な環境はPython 3.9以上、ローカルファイルの読み書きとコマンド実行が可能なAIエージェント、JavaScriptが有効なブラウザーです。Git差分の自動取得時だけGitが必要です。Pythonの外部パッケージやAPIキーは不要です。

## レビュー画面

- 起動画面：左に全ファイルのツリー、中央にAIの概要、右にレビュー対象外の一覧。
- ファイル選択後：中央にコード全文、右に行範囲と連動する解説カード。AIが理解に役立つと判断した箇所には、分岐やデータの流れを示すSVG図も添えます。
- 差分：全文の中に追加・削除を表示し、権限や名前変更・コピーなどの情報も表示します。
- 質問ボタン：ファイル・行・解説への参照付き質問文を作成。図の説明とSVG、差分の付加情報も含めて、AIエージェントに貼り付けられます。

全体・差分のどちらでも、ツールがプロジェクト内の全ファイルを走査し、選択したコードを機械的に取り込みます。対象外ファイルの本文は含めません。Markdown表示・シンタックスハイライトの素材と[ライセンス](skills/walkthrough-review/references/third-party-notices.md)を同梱し、生成した画面はネット接続なしで閲覧できます。

HTMLは作成時点のスナップショットです。コード変更後はAIに再生成を依頼してください。再ビルド時にコードと解説のハッシュを照合し、不一致を画面に表示します。ハッシュ一致は説明内容の正しさを保証するものではありません。
